YR 수학 훈련 프로그램 GitHub·Vercel 배포용

1. 이 ZIP 파일의 압축을 풉니다.
2. 압축을 푼 폴더 안의 모든 파일을 GitHub 저장소 최상위에 올립니다.
3. GitHub 첫 화면에서 app, public, package.json, vercel.json이 바로 보여야 합니다.
4. Vercel에서 해당 GitHub 저장소를 Import합니다.
5. Framework Preset은 Next.js, Root Directory는 비워 둡니다.
6. Build Command와 Output Directory는 직접 입력하지 말고 기본값을 사용합니다.

중요: ZIP 파일 자체를 GitHub 저장소 안에 올리는 것이 아니라, 압축을 푼 내용물을 올려야 합니다.

이 수정본은 GitHub에 이전 Cloudflare·Drizzle 파일이 남아 있어도
app 폴더와 Next.js 필수 파일만 형식 검사하도록 설정되어 있습니다.
