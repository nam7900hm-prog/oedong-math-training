# 외동중학교 수학 훈련 프로그램 · YR

교사용 문제 등록 흐름을 강화한 버전입니다.

## 새 기능

- `Shift + Win + S`로 캡처한 문제를 `Ctrl + V`로 바로 등록
- 문제 이미지, 정답, 해설을 한 세트로 문제보관함에 저장
- 여러 PDF 문제지·해설지를 한 번에 작업 대기열에 등록
- PDF별 예상 문항 수만큼 검수 칸을 일괄 생성
- 문제별 체크박스, 검수 상태, 검색, 삭제 및 단원 분류
- 원문 문제와 정답·해설을 함께 보는 큰 조각 제작 작업실
- 조각별 질문, 정답, 오답 2개, 교사 힌트 편집
- 학년·학기, 대단원, 중단원, 소단원 탑재 준비
- 컬러풀한 YR 브랜드 마크와 반복 학습 문구

## 교사 사용 순서

1. 교사 작업실에서 `문제 등록·보관함·조각 제작`을 선택합니다.
2. 캡처 문제는 붙여넣기 영역을 클릭하고 `Ctrl + V`를 누릅니다.
3. PDF는 여러 파일을 선택하고 파일별 예상 문항 수를 입력합니다.
4. 문제보관함에서 원문, 정답, 해설을 검수합니다.
5. `큰 화면에서 조각 만들기`를 눌러 조각을 편집합니다.
6. 학년과 단원을 선택하고 탑재 준비 상태로 저장합니다.

## 참고

현재 ZIP은 학교 내부 검토용 웹앱 시제품입니다. 캡처 문제와 입력 정보는 사용하는 브라우저의 로컬 저장소에 보관됩니다. PDF에서 문제 영역을 AI가 실제로 자동 인식·절단하고 정답·해설을 자동 연결하려면 OCR/문서 분석 서버와 학교용 저장소 연결이 추가로 필요합니다. 이번 버전은 대량 PDF를 작업 대기열에 넣고 문항 검수 칸을 일괄 생성한 뒤, 원문 캡처를 연결하여 빠르게 조각 작업으로 넘기는 흐름을 제공합니다.
