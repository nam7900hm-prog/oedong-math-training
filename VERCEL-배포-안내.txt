YR 수학 훈련 프로그램 · GitHub + Vercel 배포본

1. 이 ZIP의 압축을 풉니다.
2. ZIP 안의 파일과 폴더 전체를 GitHub 저장소의 최상위에 업로드합니다.
3. Vercel에서 해당 GitHub 저장소를 연결합니다.
4. Framework Preset은 Next.js, Root Directory는 저장소 최상위로 둡니다.
5. Build Command는 npm run build로 자동 설정됩니다.
6. Deploy를 누르면 이후 GitHub main 브랜치 변경도 자동 배포됩니다.

주의:
- ZIP 파일 자체를 GitHub 저장소 안에 올리는 것이 아니라 압축을 푼 내용을 올립니다.
- 기존 저장소를 갱신할 때는 이전 Cloudflare 전용 db, worker, drizzle.config.ts,
  vite.config.ts 파일이 남지 않도록 이 배포본의 구조를 기준으로 교체하십시오.
- 비밀번호, API 키, .env 파일은 이 ZIP에 포함되어 있지 않습니다.
