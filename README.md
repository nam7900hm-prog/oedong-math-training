# 외동중 수학 훈련 프로그램

중학교 수학 본문제를 먼저 풀고, 필요한 경우 작은 조각 문제와 다시 풀기로 이어지는 교사·학생용 학습 프로그램입니다.

## GitHub에 올리기

이 폴더 안의 파일 전체를 새 GitHub 저장소에 업로드합니다. `node_modules`, `.next`, 환경 파일은 올리지 않습니다.

## Vercel 배포

1. Vercel에서 `Add New Project`를 선택합니다.
2. 위 GitHub 저장소를 연결합니다.
3. Framework Preset이 `Next.js`인지 확인합니다.
4. 별도의 환경 변수 없이 Deploy를 실행합니다.

## 로컬 실행

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:3000`을 엽니다.

## 중요 사항

- 교사 비밀번호, 학생 정보, 문제 수정 기록은 현재 브라우저의 로컬 저장소에 저장됩니다.
- 다른 기기와 자동 공유되는 서버 데이터베이스는 아직 연결하지 않았습니다.
- 사진 PDF의 한글 OCR은 최초 실행 시 언어 자료를 불러오므로 인터넷 연결이 필요할 수 있습니다.
